# Магазин Маркет — Android-приложение продавца

Приложение продавца для сайта **mahnet.ru**. Внутри — кабинет продавца в режиме приложения (`https://mahnet.ru/?app=seller#seller`):
вход по логину и паролю магазина, наверху название магазина, ниже меню вкладок. Продавец сам выбирает «Список» или «Столбиком»,
а какие вкладки видны и в каком порядке — задаёт администратор во вкладке админки **«Приложение продавцов»**.

Вкладки по умолчанию: Добавить товар, Мои товары, Чат с покупателями, Возвраты, Чат с админом, Предупреждения админа, Срок истёк,
Отказались покупатели, Отследить мои товары. Фото товаров можно выбрать из галереи или файлов телефона либо снять на камеру («Сфотографировать» в «Добавить товар»).

## Как собрать APK на GitHub (без Android Studio)
1. На https://github.com создайте новый репозиторий (лучше приватный), например `market-seller`.
2. Распакуйте архив и загрузите **все файлы проекта** (*Add file → Upload files*), включая папку `.github`
   (если GitHub её не принимает при выборе файлов — перетащите папку мышкой целиком).
3. Вкладка **Actions** → сборка *Build Seller APK* запустится сама (или нажмите **Run workflow**).
4. Через 3–6 минут откройте зелёную сборку и внизу в **Artifacts** скачайте `seller-apk` (там `app-debug.apk`).
5. Скопируйте `app-debug.apk` на телефон и откройте. Разрешите установку из этого источника.

Если сборка красная — пришлите последние строки из шага *Build debug APK* (с `error:`), я поправлю.

## Версии и обновление поверх старого
- Версия `1.0.N`, где N — номер сборки на GitHub. Все сборки подписаны одним ключом `app/seller-release.p12`,
  поэтому новая сборка **ставится поверх** установленной, данные и вход сохраняются.
- **Не удаляйте и не меняйте `app/seller-release.p12`**; репозиторий лучше держать приватным.

## Что внутри
- `app/src/main/java/ru/mahnet/seller/MainActivity.kt` — окно сайта, выбор фото, кнопка «Назад» (из вкладки в меню), `START_URL` — адрес.
- `.github/workflows/build.yml` — автоматическая сборка на GitHub.

## Сброс версии на 1.0.0
Версия приложения — `1.0.N`: первая сборка после сброса получает **1.0.0**, дальше 1.0.1, 1.0.2…
В файле `app/version-base.txt` записано слово `auto`: при первой же сборке на GitHub оно само заменится
нужным числом (шаг «Версия (счёт с 1.0.0)» в *Actions*; затем сборка сама сохранит его в репозитории).
Ничего вписывать вручную не нужно. Если шаг «Запомнить счётчик версии» покажет красный значок (в репозитории запрещена запись
из Actions) — откройте *Settings → Actions → General → Workflow permissions* и включите *Read and write permissions*
либо впишите в `app/version-base.txt` число (номер последней сборки до сброса).
Чтобы снова сбросить счёт на 1.0.0 — запишите в `app/version-base.txt` слово `auto` и запустите сборку.
Внутренний номер Android (`versionCode`) при этом не уменьшается, поэтому новая сборка ставится поверх старой.
Если вы создали **новый репозиторий** (номера сборок начинаются с 1), старое приложение на телефоне нужно сначала удалить.
Не забудьте во вкладке админки «APK файлы» загрузить новый APK и указать версию `1.0.0` (или удалить старую запись),
иначе приложение будет предлагать «обновиться» до старой версии.
